Bill Drafter DEMO

Getting started

  1. Load the Bank. The laws this computer drafts from.
  2. Start a bill below.
  3. Add sections: amend a law, or add a standard section.
  4. Edit the law's text in the document as plain text, then Mark changes.
  5. Check the bill and make the clean copy.

Start a bill

Puts the title, the enacting clause, a blank section 1 and an effective date in this document.
