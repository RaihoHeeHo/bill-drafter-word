Bill Drafter for Word

A demo Word add-in: amendments from your own copy of the laws, standard sections, drafting checks, and Akoma Ntoso export.

Download manifest.xml

Add it to Word for Windows

  1. Save manifest.xml in a folder on a network share, e.g. \\server\share\Word add-ins.
  2. Word: File > Options > Trust Center > Trust Center Settings > Trusted Add-in Catalogs. Add the folder's network path, tick Show in Menu, restart Word.
  3. Home > Add-ins > More Add-ins > Shared Folder > Bill Drafter (demo) > Add.

Word on the web: Home > Add-ins > More Add-ins > My Add-ins > Upload My Add-in, then pick manifest.xml.

First use

  1. Open Home > Bill Drafter, go to the Bank tab and choose the folder with the law files. They stay on this computer.
  2. On Draft, start a new bill, then amend sections, add standard sections and run Checks.
  3. Export converts the bill to Akoma Ntoso XML.

A demo by an individual, not an official product of any state agency. Nothing is installed on the computer; the add-in's code loads from this site and the laws never leave the computer.
